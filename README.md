# ChatFlow

ระบบเว็บแอปพลิเคชันสำหรับสุ่มข้อความตอบกลับอัตโนมัติ ด้วย Flask + JSON

## 📦 ความสามารถ

- รองรับการสุ่มตอบข้อความจาก keyword
- แสดงผลบนหน้าเว็บผ่าน HTML (Flask Template)
- สามารถปรับคำตอบใน `responses.json` ได้ตามต้องการ
